# Совместная доска задач

Кроссплатформенное клиент-серверное приложение для совместной работы с доской задач в локальной сети. Несколько пользователей подключаются к одному серверу, видят общую доску, редактируют карточки и получают изменения в реальном времени.

![Скриншот доски](screenshots/board.svg)

## Возможности

- Создание и удаление колонок.
- Добавление, редактирование, удаление и перемещение карточек задач.
- Автоматическая синхронизация изменений между всеми подключёнными клиентами через SignalR.
- Отображение текущих пользователей онлайн.
- Локальное сохранение последней синхронизированной копии доски для офлайн-просмотра.
- Переключение интерфейса между русским и английским языками.
- MVVM-архитектура: View не содержит бизнес-логики и сетевых вызовов.

## Технологии

- `.NET 8` для клиента, сервера и общей библиотеки моделей.
- `Avalonia` для кроссплатформенного desktop-интерфейса на Windows и macOS.
- `CommunityToolkit.Mvvm` для ViewModel и команд.
- `ASP.NET Core SignalR` для синхронизации в реальном времени.
- Встроенный сервер в клиенте для запуска без отдельного терминала.
- UDP-обнаружение серверов в локальной сети.
- `JSON`-кэш на клиенте для хранения последней версии доски.
- `xUnit` для автоматических тестов.
- `DocFX` для автособираемой документации.

## Запуск

Запустите клиент:

```bash
dotnet run --project src/TaskBoard.Client
```

Если этот компьютер должен быть сервером, нажмите в окне клиента `Запустить сервер`. Приложение автоматически поднимет встроенный SignalR-сервер, подставит локальный адрес и начнёт показывать себя другим клиентам в локальной сети.

На втором компьютере тоже запустите клиент:

```bash
dotnet run --project src/TaskBoard.Client
```

Выберите найденный сервер в списке `Найденные серверы` и нажмите `Подключиться`.

Если автоматическое обнаружение не сработало из-за firewall или настроек сети, сервер можно запустить вручную:

```bash
dotnet run --project src/TaskBoard.Server --urls http://0.0.0.0:5000
```

После этого в клиенте можно указать адрес сервера вручную:

- `http://localhost:5000`, если клиент и сервер запущены на одной машине;
- `http://<IP-адрес-сервера>:5000`, если клиент подключается с другого компьютера в локальной сети.

## Инструкция пользователя

1. Введите имя пользователя.
2. Если этот компьютер должен быть сервером, нажмите `Запустить сервер`.
3. На втором компьютере выберите сервер в списке `Найденные серверы`.
4. Нажмите `Подключиться`.
5. Добавьте колонку через поле `Название колонки`.
6. Нажмите `Добавить задачу` в нужной колонке.
7. Выберите карточку, измените заголовок или описание и нажмите `Сохранить`.
8. Используйте кнопки `Влево` и `Вправо`, чтобы перемещать выбранную карточку между колонками.
9. Используйте кнопки `RU` и `EN`, чтобы переключать язык интерфейса.

## Примеры работы

### Пример 1. Запуск на одном компьютере

Откройте терминал и запустите клиент:

```bash
dotnet run --project src/TaskBoard.Client
```

В окне клиента нажмите `Запустить сервер`. Приложение само поднимет сервер и подключится к нему.

Если нужно проверить ручной режим, сервер можно запустить отдельно:

```bash
dotnet run --project src/TaskBoard.Server --urls http://localhost:5000
```

В ручном режиме в окне клиента укажите:

- сервер: `http://localhost:5000`;
- пользователь: `Максим`.

После подключения клиент получает текущее состояние доски и показывает пользователей онлайн.

### Пример 2. Работа двух пользователей в локальной сети

На компьютере, который будет сервером, запустите клиент:

```bash
dotnet run --project src/TaskBoard.Client
```

Нажмите `Запустить сервер`. На другом компьютере в той же сети запустите клиент:

```bash
dotnet run --project src/TaskBoard.Client
```

Выберите сервер в списке `Найденные серверы` и нажмите `Подключиться`. Если пользователь `Анна` создаёт колонку `В работе`, пользователь `Максим` увидит эту колонку автоматически без перезапуска приложения.

### Пример 3. Создание карточки задачи

1. Создайте колонку `К выполнению`.
2. Нажмите `Добавить задачу`.
3. Выберите созданную карточку.
4. Введите заголовок `Подготовить отчёт`.
5. Введите описание `Добавить скриншоты, инструкции запуска и ссылку на документацию`.
6. Нажмите `Сохранить`.

После сохранения карточка синхронизируется со всеми подключёнными клиентами.

### Пример 4. Перемещение задачи

1. Создайте колонки `К выполнению`, `В работе`, `Готово`.
2. Выберите карточку в колонке `К выполнению`.
3. Нажмите `Вправо`.

Карточка переместится в следующую колонку, а сервер отправит обновлённое состояние всем клиентам.

### Пример 5. Офлайн-доступ

После успешной синхронизации клиент сохраняет последнюю копию доски в локальный JSON-кэш. Если сервер временно недоступен, приложение всё равно откроет последнюю сохранённую версию доски для просмотра.

## Поддерживаемые платформы

- Windows 10/11.
- macOS.

Клиент построен на Avalonia, поэтому не использует WPF и не привязан к Windows-only UI. Сборка на Windows и macOS проверяется автоматически в GitHub Actions.
